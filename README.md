# CuratedBets for Android — public beta downloads

This repository hosts **signed Android installers (APK files)** for the CuratedBets public beta, attached to each
[Release](../../releases). It contains no source code.

**Get the app from the official page:** <https://www.curatedbets.club/download>.
That page always links to the current approved build. Please share that link, not individual files.

CuratedBets is a free NFL player-prop information app: observed lines and prices, line history, season stats and
game logs. It has no account, no ads and no sportsbook links. It is information only, not betting advice.

## Verify a download (optional)

Each release lists these details, and they match what www.curatedbets.club/download shows:

| | |
|---|---|

| Signing certificate SHA-256 | `D6C7B60DF97B2FE8923D8B590A04E7AB3E44EF1F2C31FC7E07F45BA1F2B2452B` |
| File SHA-256, size, version, version code | listed in each release's notes |

Every beta is signed with the same certificate, so a newer beta installs over an older one. If a file's certificate
differs, **do not install it**.
